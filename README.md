# Orden de Trabajo - CEDENAR S.A.E.S.P.

Formulario digital de Orden de Trabajo para Centrales Eléctricas de Nariño S.A.E.S.P.

## Archivos

### 1. orden_trabajo.html
- **Versión funcional completa** - Todas las funciones JavaScript operan correctamente
- Usa archivo externo `cedenarlogo.png` para el logo
- Para uso local con todas las funcionalidades

### 2. index.html
- **Vista previa del formulario** - Sin JavaScript (solo diseño)
- Logo embebido en base64 (no requiere archivos externos)
- Ideal para visualizar/presentar el diseño

### 3. cedenarlogo.png
- Archivo del logo de CEDENAR

## Uso

1. **Para desarrollo local**: Usa `orden_trabajo.html` con `cedenarlogo.png` en la misma carpeta
2. **Para presentación**: Usa `index.html` que incluye el logo embebido

## Características del Formulario

- Diseño responsivo
- Firma táctil
- Fotos con GPS
- Generación de PDF
- Gestión de materiales
- Códigos de fallas

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Canvas API
- Geolocation API
